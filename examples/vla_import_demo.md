# Zotero 文献导入案例展示（具身智能 VLA 10 篇精选）

本文件展示了将文献调研产出的 10 篇精选论文按推荐阅读顺序导入 Zotero 的实际层级与标题规范：

## 1. Zotero 树状集合结构

```text
📁 我的文库 (My Library)
└── 📁 VLA (大类目录)
    ├── 📁 01_视觉语言动作基座 (子目录)
    │   ├── 01. RT-1: Robotics Transformer for Real-World Control at Scale
    │   ├── 02. PaLM-E: An Embodied Multimodal Language Model
    │   └── 03. RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control
    ├── 📁 02_架构解耦与世界模型 (子目录)
    │   ├── 04. RoboFlamingo: Vision-Language Foundation Models as Effective Robot Imitators
    │   ├── 05. GR-1: Unleashing Large-Scale Video Generative Pre-training for Visual Robot Manipulation
    │   └── 06. 3D-VLA: A 3D-Centric Embodied Foundation Model
    └── 📁 03_开源通用与高频流匹配 (子目录)
        ├── 07. Octo: An Open-Source Generalist Robot Policy for [X]-Embodiment Actions
        ├── 08. OpenVLA: An Open-Source Vision-Language-Action Model
        ├── 09. π0: A Vision-Language-Action Flow Model for Generalist Robot Manipulation
        └── 10. CogACT: A Foundational Vision-Language-Action Model for Synergizing Cognition and Action
```

## 2. 导入元数据与 PDF 附件对应
- 每篇条目均附带原文链接与官方 PDF 全文附件。
- 在 Zotero 中点击标题列即可一键按照 `01.` ~ `10.` 升序浏览。
